== Description ==

NRD Form Builder Premium is a feature-rich WordPress plugin designed for both beginners and advanced users to create stunning forms effortlessly. Whether you need contact forms, surveys, or custom registration forms, NRD Form Builder Premium provides a seamless experience.

**Key Features:**
* Drag-and-drop form builder interface
* Fully responsive forms
* Conditional logic for fields
* Multi-step forms
* Spam protection (CAPTCHA & Honeypot)
* Email notifications & integrations
* Export submissions to CSV
* Integration with Google Sheets

**Why Choose NRD Form Builder Premium?**
* Easy to use for beginners
* Advanced customization for developers
* Reliable and secure
* Regular updates with premium support

**Installation Instructions:**
1. Upload the `nrd-form-builder-premium` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Enter your license key in the plugin settings to unlock all premium features.

**Frequently Asked Questions:**

= Is this plugin compatible with the latest WordPress? =
Yes, it is tested up to WordPress 6.8 and requires at least PHP 7.4.

= Can I create multi-step forms? =
Yes, multi-step forms are fully supported with conditional logic and progress tracking.

= How do I update the plugin? =
The plugin supports automatic updates via GitHub for active licenses. Make sure your license key is valid.
